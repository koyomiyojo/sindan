# 陰陽五行で知る わたしの十干タイプ

生年月日から、生まれた日の日干（十干）タイプを調べる静的Webアプリです。HTML・CSS・JavaScriptだけで動作し、入力した生年月日をサーバーへ送信・保存しません。API、Cookie、アクセス解析、広告、外部通信は使用していません。

## ファイル構成

- `index.html`：画面
- `style.css`：デザイン
- `script.js`：日干の計算と画面操作
- `images/`：10枚の画像を置くフォルダ

## 画像の入れ方

`images` フォルダへ、次の名前で画像を入れてください。タイトル画面には `cover_title.png` を使用します。画像がない・読み込めない場合は、五行色の背景と十干の文字を表示します。

| 十干 | 画像ファイル名 |
| --- | --- |
| 甲 | `kouboku.png` |
| 乙 | `otsuboku.png` |
| 丙 | `heika.png` |
| 丁 | `teika.png` |
| 戊 | `bodo.png` |
| 己 | `kido.png` |
| 庚 | `koukin.png` |
| 辛 | `shinkin.png` |
| 壬 | `jinsui.png` |
| 癸 | `kisui.png` |

別の名前に変える場合は、`index.html` 内の `const I` にある該当するファイル名も同じ名前へ変更します。画像は縦横比を保ち、画像全体が見えやすい `object-fit: contain` で表示します。

## 日干の計算方法

日干は十干・十二支が組み合わさる60日周期で求めます。`script.js` はグレゴリオ暦の日付からユリウス日番号（JDN）を整数演算で算出し、基準日との差を60で割った余りを使います。時刻・節入りは使いません。

- 基準日：2026年9月19日
- 基準日の干支：丙申（甲子を0とする60干支番号は32）
- JDN：2461303

入力値を `Date` のローカル時刻で解釈せず、日付の各数値からJDNを計算するため、端末のタイムゾーンや夏時間による日付ずれを防ぎます。コード内では確認例として、2026年9月18日＝乙未、9月19日＝丙申（日干：丙）、9月20日＝丁酉を記載しています。

## PCで確認する方法

1. このフォルダの `index.html` をダブルクリックします。
2. ブラウザで生年月日を入力し、「わたしの十干タイプを見る」を押します。
3. 2026年9月19日を入力して「丙（へいか）」になることも確認してください。

## GitHubへのアップロードとGitHub Pages公開

1. GitHubにログインし、右上の `+` → **New repository** で新しいリポジトリを作成します。
2. リポジトリ名を入力し、**Create repository** を押します。
3. リポジトリ画面で **Add file** → **Upload files** を選び、このフォルダ内の `index.html`、`style.css`、`script.js`、`README.md` と `images` フォルダをアップロードします。
4. **Commit changes** を押します。
5. リポジトリの **Settings** → **Pages** を開きます。
6. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch を `main`、フォルダを `/(root)` にして **Save** を押します。
7. 数分後に表示される公開URLを開き、画像・入力エラー・判定結果を確認します。

公開後は、スマートフォンでも表示が崩れないこと、10種類の画像名が正しいこと、未来日・未入力・1900年より前の日付で適切な案内が出ることを確認してください。
